## 0. 读法

- 编号：`域-序号`。域：PLT 平台管理、CON 连接状态、MOD 模型列表、SPD-A 对话页速度、SPD-B 平台页测速、ADV 高级配置、GEN 生成参数、CHAT 对话、HIS 历史、CALL 语音通话、USE 用量、SET 设置页、NFR 非功能。
- 优先级：**P0** 本次必须交付；**P1** 本次交付，但可排在 P0 之后；**P2** 不做，只记录。
- 验收方式：**U** 单元测试（JVM，`testDebugUnitTest`）；**S** 截图（Robolectric 预检或真机）；**M** 真机手动步骤；**B** 构建/静态检查。每条验收都写成"做什么 → 应看到什么"，能直接判对错。
- 页面：对话页（AI 页签）、历史（对话页上的底部面板，按独立页规格化）、设置页、平台页、通话页。
- 引号里的文字就是界面文案，实施时原样进 `strings.xml`。`{x}` 为变量。

## 1. 术语表

一个概念只用一个词；左列以外的说法不出现在界面上。

| 术语 | 定义 | 不用 |
|---|---|---|
| 平台 | 一份接入配置：模板＋名称＋API Key＋接口地址＋协议＋模型列表。同一模板可建多份 | 服务商、供应商、Provider、渠道 |
| 模板 | 平台的出厂类型：OpenAI、Anthropic、DeepSeek、SenseNova、自定义 OpenAI 兼容、自定义 Anthropic 兼容 | 类型、预设 |
| 模型 | 平台下的一个模型 ID（可带显示名） | Model、引擎 |
| 当前模型 | 全局唯一的（平台, 模型），新消息用它回答 | 默认模型、活动模型 |
| API Key | 平台密钥 | 令牌、Token、密钥、Key |
| 接口地址 | 用户填的 Base URL（如 `https://api.openai.com`） | Base URL、API 地址、端点 |
| 请求地址 | 接口地址＋协议路径的完整 URL，只读预览 | Endpoint |
| 协议 | Chat Completions / Responses / Messages | 接口类型、API 格式 |
| 连接状态 | 平台最近一次"测试"的结论 | 健康度、可用性 |
| 测试 | 对平台发一次最小流式请求以确认能用 | 检测、校验、Ping |
| 测速 | 平台页对模型测首字耗时 | 跑分、延迟测试 |
| 首字 | 从发出请求到收到第一个输出片段（含思考过程片段）的耗时 | 首 token、TTFT、延迟 |
| 实时速度 | 生成中按已收内容估算的输出速度，带"≈" | 瞬时速度 |
| 平均速度 | 一条回答结束后：输出 token ÷（结束时刻 − 首字时刻） | 吞吐、TPS |
| 上下文 | 模型的上下文窗口长度，显示为 `128K` / `1M` | Context、窗口 |
| 上下文条数 | 每次请求带上的历史消息条数（设置项） | 记忆条数 |
| 拉取模型 | 从平台的模型列表接口取回模型 | 同步、获取、刷新 |
| 手动添加 | 用户手填模型 ID | 自定义模型 |
| 已下线 | 已添加、但最近一次拉取时远端不再返回的模型 | 失效、过期 |
| 生成参数 | 温度、Top P、最大输出三项 | 采样参数、高级参数 |
| 全局参数 | 设置页里的生成参数，可作用于全部或指定模型 | 默认参数 |
| 来源 | 某个生成参数实际生效值的出处：此模型 / 全局 / 平台默认 | — |
| 平台默认 | 不发送该参数，由平台决定 | 模型默认、自动 |
| 最大输出 | 单条回答最多输出的 token 数 | Max Tokens、最大长度 |
| 对话 / 新对话 / 历史对话 | 一组消息 / 尚无消息的对话 / 已保存的对话 | 会话、聊天、Session |
| 回答 | 助手的一条消息 | 回复、响应 |
| 思考过程 | 模型返回的推理内容 | 推理、思维链、Reasoning |
| 重新生成 / 重试 / 停止 | 对最后一条回答重新请求 / 失败后再请求 / 中止生成 | 再来一次、取消生成 |
| 语音通话 | 通话页的语音对话 | 语音模式、实时对话 |
| 说话方式 | 级联（转写→对话模型→朗读）或 全双工（实时模型） | 语音模式 |
| 转写模型 / 实时模型 / 朗读声音 | 语音转文字的模型 / 全双工用的模型 / 系统 TTS 的声音 | ASR、Realtime、TTS 音色 |
| 用量 | 请求次数、输入 token、输出 token、费用的统计 | 消耗、账单 |
| token | 计量单位，统一小写 | 令牌、Token、词元 |
| 删除 / 清空全部 | 删一项 / 删同类全部 | 移除、清除 |

数值格式（全模块统一，`AiFormat` 单测覆盖）：

| 量 | 规则 | 例 |
|---|---|---|
| 耗时（首字） | <1000 ms 显示整数 ms；1–10 s 一位小数；≥10 s 整数 s | `640 ms` `1.2 s` `12 s` |
| 速度 | 整数 tok/s；实时值前加 `≈` | `41 tok/s` `≈ 38 tok/s` |
| 上下文 | ≥1,000,000 用 M，≥1,000 用 K，去尾零 | `128K` `1M` `1.5M` |
| token 数 | 千分位 | `1,234 tokens` |
| 相对时间 | <1 分钟"刚刚"；<60 分钟"{n} 分钟前"；当天"{n} 小时前"；昨天"昨天"；更早"{M}月{D}日"；跨年"{YYYY}年{M}月{D}日" | `3 分钟前` |
| 通话时长 | `m:ss`，≥1 小时 `h:mm:ss` | `3:21` |
| API Key 掩码 | 长度 ≥10：前 3 ＋ `••••` ＋ 后 4；否则全掩；空为"未填写" | `sk-••••a1b2` |

## 2. PLT 平台管理

- **PLT-01 平台列表**（P0）
  - 定义：设置页"平台"分组按添加顺序列出全部平台。每行：名称；副行 `{模板} · {N} 个模型 · {连接状态摘要}`；当前模型所在平台带"当前"标签。
  - 验收：U 依次添加 A、B、C 三个平台，列表顺序为 A、B、C；把当前模型设为 B 的模型后，只有 B 带"当前"。S 设置页截图可见副行三段。
- **PLT-02 添加平台**（P0）
  - 定义：点"添加平台"弹出模板面板，六个模板（OpenAI、Anthropic、DeepSeek、SenseNova、自定义 OpenAI 兼容、自定义 Anthropic 兼容），每项带一行说明。选中即创建平台并打开它的平台页；不选关闭面板则不创建。
  - 验收：U 选 OpenAI 后平台数 +1，新平台 `templateId=openai`、接口地址为模板默认值；M 关闭面板不产生平台。
- **PLT-03 同模板多份与命名**（P0）
  - 定义：同一模板可添加多次。默认名＝模板名；已存在同名时加序号 `OpenAI 2`、`OpenAI 3`（取最小未用序号）。自定义模板默认名"自定义 OpenAI 兼容"/"自定义 Anthropic 兼容"。
  - 验收：U 连续添加三次 OpenAI，名称为 `OpenAI`、`OpenAI 2`、`OpenAI 3`；删除 `OpenAI 2` 后再添加，得到 `OpenAI 2`。
- **PLT-04 改名**（P0）
  - 定义：平台页身份卡可改名称。保存前去首尾空白；1–32 个字符；不得与其他平台重名。不合法时行内显示原因（"名称不能为空" / "最多 32 个字" / "已有同名平台"），不保存，失焦后恢复原值。
  - 验收：U 三种非法输入各返回对应错误且存储未变；合法输入立即持久化。
- **PLT-05 模板只读**（P0）
  - 定义：身份卡显示模板名，不可修改；需要换模板就新建平台。
  - 验收：S 身份卡模板行无箭头、不可点击。
- **PLT-06 当前模型**（P0）
  - 定义：全局唯一。可在平台页模型行菜单"设为当前"、对话页模型面板、设置页"当前模型"行设置。只有对话类模型可设为当前。当前模型被删除（模型或其平台）后置空。
  - 验收：U 设为当前后 `AiSelection` 为（平台, 模型）；删除该模型后为空；非对话模型调用设为当前返回错误。
- **PLT-07 删除平台**（P0）
  - 定义：平台页危险区"删除平台"。确认框写明后果："将删除「{名称}」的 API Key、{N} 个模型和测速结果。历史对话会保留，但不能再用这个平台回答。"按钮"删除"（危险色）/"取消"。删除后关闭平台页回到设置页。
  - 验收：U 删除后平台不在列表、其 API Key 从安全存储移除、历史对话条数不变；若删的是当前平台则当前模型为空。M 取消不删除。
- **PLT-08 即时保存**（P0）
  - 定义：平台的所有可编辑项在输入失焦或选择后立即保存，无"保存"按钮；杀进程重开后一致。API Key 只存在加密存储（现有 `EncryptedSecretStore`）。
  - 验收：U 修改后新建仓储实例读回一致；B 普通配置 JSON 中不出现 API Key 明文。

## 3. CON 连接状态

- **CON-01 状态集合**（P0）
  - 定义：五态，主文案固定：
    - 未测试："未测试"
    - 测试中："测试中…"（同时"测试"按钮变"取消"）
    - 正常："正常 · 首字 {耗时}"
    - 失败："失败 · {失败分类文案}"（文案见 CON-05 表）
    - 需重测："配置已改，需重新测试"
  - 副行（有结果时）："用 {模型} 测试 · {相对时间}"。
  - 验收：U `AiConnectionMapper` 对五态各输出对应主文案和副行；S 平台页五态各一张截图。
- **CON-02 测试请求**（P0）
  - 定义：点"测试"用测试模型发一次最小流式真实请求（用户消息 `Hi`，最大输出 16，不带系统提示词与生成参数）。收到第一个输出片段即判正常并主动断开，首字＝发出→首片段。15 s 内无片段判超时失败。不额外请求模型列表。
  - 验收：U 用 MockWebServer：正常 SSE → 状态正常且首字有值，且服务端只收到 1 个请求；401 → 失败·鉴权；不响应 → 15 s 后失败·超时（测试用虚拟时钟）。
- **CON-03 测试模型**（P0）
  - 定义：默认取当前模型（若属于本平台），否则模型列表中第一个对话模型。用户可在连接卡"测试模型"行改选，选择持久化。所选模型被删除后回到默认规则。
  - 验收：U 三种情况（当前模型在本平台 / 不在 / 所选被删）各得到预期模型。
- **CON-04 前置条件**（P0）
  - 定义：不满足时"测试"按钮禁用，主文案位置显示原因（优先级从上到下取第一个）："先填写 API Key"、"先填写接口地址"、"接口地址格式不对"、"先添加模型"、"当前离线"。
  - 验收：U 每个条件单独不满足时按钮禁用并给出对应原因；多个不满足时取最上面一个。
- **CON-05 失败分类与指向**（P0）
  - 定义：失败按 `AiFailureKind` 映射文案与"要改的行"。点失败状态行滚动到并高亮对应行（高级区需要时自动展开）。

    | 分类 | 文案 | 指向 |
    |---|---|---|
    | AUTHENTICATION | API Key 无效 | API Key 行 |
    | PERMISSION | 没有权限使用此模型 | 测试模型行 |
    | QUOTA | 余额或额度不足 | 无（副行加"请到平台官网处理"） |
    | RATE_LIMITED | 请求太频繁，稍后再试 | 无 |
    | NOT_FOUND | 地址或模型不存在 | 接口地址行（高级） |
    | BAD_REQUEST | 请求被拒绝 · {平台返回的简短信息} | 协议行（高级） |
    | SERVER | 平台服务出错（{HTTP 状态}） | 无 |
    | NETWORK | 网络连接失败 | 无 |
    | TIMEOUT | 15 秒内没有响应 | 无 |
    | PROTOCOL | 返回内容无法解析 | 协议行（高级） |
    | 其他 | 未知错误 | 无 |
  - 验收：U 映射表逐项覆盖；M 用错误 API Key 测试后点失败行，页面滚动到 API Key 行且该行高亮 1 s。
- **CON-06 结果持久化与过期**（P0）
  - 定义：保存（状态、首字、失败分类、简短信息、测试模型、时间、配置指纹）。配置指纹＝接口地址＋协议＋API Key 摘要＋测试模型。重开后显示上次结果；当前指纹与结果指纹不同 → 需重测。
  - 验收：U 正常结果保存后改 API Key → 需重测；改回原 Key → 恢复为正常（指纹一致）。
- **CON-07 可取消**（P0）
  - 定义：测试中点"取消"立即中止请求，状态回到测试前的状态，不写新结果、不写用量。
  - 验收：U 取消后状态等于测试前状态，存储未变，MockWebServer 连接被关闭。
- **CON-08 离开页面**（P1）
  - 定义：测试进行中离开平台页，测试继续到结束并写结果（由应用级作用域持有）；回到页面看到结果。
  - 验收：M 测试中返回设置页，再进入平台页能看到结果。

## 4. MOD 模型列表

- **MOD-01 标题与计数**（P0）
  - 定义：模型区标题 "模型 · {N}"，N＝全部模型数（含非对话、已下线）。
  - 验收：U N 与列表条数一致。
- **MOD-02 行内容**（P0）
  - 定义：主行＝显示名（无则 ID）；有显示名时 ID 作为第三行小字。事实行按顺序拼接，缺项省略：测速结论（"首字 645 ms" / "未测速" / "测速失败 · {分类文案}" / "测速中…"）、上下文（"128K 上下文"）。标记：当前模型"当前"，已下线"已下线"，非对话模型显示类型标签（"向量"/"图像"/"语音"/"审核"/"其他"）并以"不测速"取代测速结论。测速结果过期（指纹不符）时首字值后加"（配置已改）"并降为次要色。
  - 验收：U `AiModelRowMapper` 对 8 种组合（未测/成功/失败/测速中 × 有无上下文，非对话，已下线，过期）输出逐字一致；S 截图覆盖。
- **MOD-03 排序**（P0）
  - 定义：当前模型置顶，其余按添加顺序（拉取的按接口返回顺序追加）。测速完成不自动重排。
  - 验收：U 设第 3 个为当前后它排第 1，其余相对顺序不变；测速后顺序不变。
- **MOD-04 搜索**（P0）
  - 定义：模型数 >8 时标题下出现搜索框；匹配 ID 与显示名，不区分大小写，子串匹配；无结果显示"没有匹配「{q}」的模型"。搜索不影响批量测速范围之外的数据（批量只作用于当前筛选结果，见 SPD-B-04）。
  - 验收：U 9 个模型时 `showSearch=true`，8 个时 false；`gpt` 命中 `GPT-4o`。
- **MOD-05 添加入口**（P0）
  - 定义：标题行"添加 ▾"菜单两项："拉取模型"、"手动添加"。拉取在缺 API Key 或接口地址时禁用并显示原因。
  - 验收：S 菜单截图；U 缺 Key 时拉取项禁用原因为"先填写 API Key"。
- **MOD-06 拉取模型**（P0）
  - 定义：调用平台模型列表接口。成功后弹出选择面板：远端模型按类型分组（对话在前），带搜索；已添加的显示"已添加"且不可勾选；默认不勾选任何项；底部按钮"添加 {N} 个"（N=0 禁用）。拉取中标题行显示"拉取中…"进度。失败在模型区顶部显示错误条"拉取失败 · {分类文案}"＋"重试"，不弹 toast。
  - 验收：U MockWebServer 返回 5 个模型、其中 2 个已添加 → 面板 3 个可选；勾 2 个确认后模型数 +2，顺序为接口顺序；401 → 错误条文案正确。
- **MOD-07 已下线**（P0）
  - 定义：拉取成功时，已添加但不在返回结果中的模型（手动添加的除外）标记"已下线"；不自动删除；再次出现时清除标记。
  - 验收：U 拉取结果去掉 X → X 标已下线；手动添加的 Y 不受影响；下次结果包含 X → 标记清除。
- **MOD-08 手动添加**（P0）
  - 定义：面板字段：模型 ID（必填，去空白，本平台内不可重复）、显示名（可选）、上下文（可选，正整数，单位 K）、类型（对话/向量/图像/语音/审核/其他，默认对话）。按钮"添加"在 ID 合法前禁用。添加后不自动测速。
  - 验收：U 重复 ID 返回"已有这个模型"；空 ID 按钮禁用；上下文输入 `128` 保存为 128,000（K＝1000，与显示规则一致）。
- **MOD-09 行菜单**（P0）
  - 定义：对话模型："设为当前"（已是当前则不显示）、"测速"、"生成参数"、"编辑"、"删除"。非对话模型："编辑"、"删除"。编辑面板同手动添加，ID 只读。
  - 验收：U 菜单项列表按模型类型逐字一致。
- **MOD-10 多选与批量**（P0）
  - 定义：长按模型行进入多选；标题行换成操作条"已选 {N}"＋"全选"＋"测速"＋"删除"＋"完成"。多选中非对话模型可选（可删除），但不计入测速。
  - 验收：U 选 3 个（含 1 个非对话）点测速 → 实际测 2 个。
- **MOD-11 删除模型**（P0）
  - 定义：单个或批量删除都弹确认："删除 {N} 个模型？"；包含当前模型时追加"其中包含当前模型，删除后需要重新选择。"（Q14）。删除同时删其测速结果与单模型生成参数。
  - 验收：U 删除后模型、测速结果、参数三处都无残留；含当前模型时当前模型为空。
- **MOD-12 删除测速失败的**（P1）

## 6. SPD-A 对话页速度（真实对话采样）

- **SPD-A-01 首字**（P0）
  - 定义：每条回答记录发出请求时刻与首个输出片段（含思考过程片段）时刻，差值为首字，保存到消息。
  - 验收：U 伪造事件流（t0 发送、t0+800 首片段）→ 消息首字 800 ms。
- **SPD-A-02 实时速度**（P0）
  - 定义：生成中每 0.5 s 刷新一次"≈ {N} tok/s"＝估算 token ÷（现在 − 首字时刻）。估算：CJK 字符每字 1 token，其他字符每 4 个 1 token（Q2）。首字后 <0.5 s 不显示。
  - 验收：U 估算函数：`"你好世界"`→4，`"abcdefgh"`→2；0.4 s 时返回空。S 生成中截图可见"≈"。
- **SPD-A-03 平均速度**（P0）
  - 定义：回答结束后用平台回报的输出 token 计算：输出 token ÷（结束 − 首字），替换实时值；平台未回报 token 时用估算值并保留"≈"。输出 <2 token 或（结束 − 首字）<100 ms 不显示速度。停止的回答按停止时刻计算。
  - 验收：U 输出 410 token、首字后 10 s 结束 → `41 tok/s`；无 usage → `≈ …`；1 token → 不显示。
- **SPD-A-04 不额外请求**（P0）
  - 定义：速度只来自真实对话流，不为测速发任何请求。
  - 验收：U 一次发送只产生 1 个 HTTP 请求（MockWebServer 计数）。
- **SPD-A-05 每轮平均的含义**（P0，Q3）
  - 定义："每轮平均"＝每条回答自己的平均速度，显示在该回答的元信息行；不做会话平均。
  - 验收：S 两条回答各自显示不同速度。

## 11. CALL 语音通话

- **CALL-01 入口与前置**（P0）
  - 定义：对话页"语音通话"打开通话页。前置：级联＝当前模型＋转写模型（同平台或指定平台）＋系统 TTS 可用；全双工＝实时模型（平台支持）；以及麦克风权限。缺项时通话页显示禁用态：列出缺少的项（"未设置转写模型"等）＋"去设置"，不开始通话。
  - 验收：U `AiCallReadinessPolicy` 各缺项输出；S 禁用态截图。
- **CALL-02 状态**（P0）
  - 定义：接通中"正在接通…"、聆听"在听"、思考"在想"、说话"在说"、静音"已静音"、失败"通话中断 · {分类文案}"、结束"通话结束 · {时长}"。任一时刻只显示一种。
  - 验收：U 状态机迁移表（含非法迁移被忽略）。
- **CALL-03 动效**（P0）
  - 定义：只在聆听、思考、说话三态播放（不同形态）；其他状态静止。系统"移除动画"开启时全部静止。
  - 验收：U 状态→动效映射；M。
- **CALL-04 字幕**（P0）
  - 定义：显示最近一轮：用户一句（转写结果）＋回答一句（随朗读进度出现）。新一轮开始替换旧字幕。
  - 验收：S 截图。
- **CALL-05 控制**（P0）
  - 定义：底部三按钮"静音"（切换）、"音频输出"（扬声器/听筒/蓝牙耳机，耳机仅在连接时出现）、"挂断"（危险色）。
  - 验收：M 切换输出后声音从对应设备发出。
- **CALL-06 打断**（P0）
  - 定义：说话中检测到用户开口或点击画面 → 立即停止朗读并进入聆听。
  - 验收：U 状态机：说话＋用户语音事件 → 聆听，并调用停止朗读。
- **CALL-07 麦克风权限**（P0）
  - 定义：未授权显示说明"语音通话需要使用麦克风"＋"授权"；被永久拒绝时按钮改"去系统设置"。
  - 验收：S 两种截图（Robolectric 模拟权限状态）。
- **CALL-08 朗读声音不可用**（P0）
  - 定义：系统 TTS 无可用引擎或缺中文声音时提示"没有可用的朗读声音"＋"打开系统朗读设置"。
  - 验收：M。
- **CALL-09 失败与结束**（P0）
  - 定义：失败显示分类文案＋"重新接通"/"挂断"；结束显示时长 1.5 s 后返回对话页。
  - 验收：U 状态机；M。
- **CALL-10 记录**（P0，Q8）
  - 定义：通话内容默认不写入对话历史；写入用量（来源"通话"）。
  - 验收：U 一次通话后对话数不变、用量来源=通话 +N。

## 12. USE 用量

- **USE-01 入口**（P0）
  - 定义：设置页"用量"分组首行显示"今天 {N} 次请求 · {T} tokens"，点击打开用量面板。
  - 验收：S。
- **USE-02 范围**（P0）
  - 定义：分段选择"今天"、"近 7 天"、"近 30 天"、"全部"，默认"今天"。
  - 验收：U 边界时刻落在正确范围。
- **USE-03 指标**（P0）
  - 定义：请求次数（括号内失败数"其中 {M} 次失败"）、输入 token、输出 token；费用只在该范围内至少有一条平台回报费用时显示（多币种分列），否则不显示该项。
  - 验收：U 无费用记录时 `showCost=false`。
- **USE-04 按模型**（P0）
  - 定义：按（输入＋输出 token）降序列出前 5 个模型"{平台} · {模型}"，其余合并为"其他"。
  - 验收：U 7 个模型 → 5 行＋"其他"。
- **USE-05 按来源**（P1）
  - 定义：来源"对话"、"语音通话"、"连接测试"、"测速"各自请求次数。旧记录无来源字段按"对话"计。
  - 验收：U 旧 JSON 样本读入来源为对话。
- **USE-06 空态**（P0）
  - 定义："这段时间没有用量"。
  - 验收：S。
- **USE-07 清空用量**（P1）
  - 定义：面板底部"清空用量记录"，确认后清空。
  - 验收：U。

## 13. SET 设置页

- **SET-01 分组顺序**（P0）
  - 定义：自上而下固定：当前模型 → 平台 → 对话 → 生成参数 → 说话方式 → 用量 → 隐私说明。
  - 验收：S 长截图顺序一致。
- **SET-02 当前模型行**（P0）
  - 定义："当前模型"，值"{平台} · {模型}"或"未选择"，点击打开模型面板（同 CHAT-02）。
  - 验收：S。
- **SET-03 对话**（P0）
  - 定义："系统提示词"（多行，最多 4000 字，显示前两行摘要，点进编辑面板）；"上下文条数"（0–50，0 显示"全部"，默认 20）；"显示思考过程"开关（默认开）。
  - 验收：U 校验与默认值。
- **SET-04 说话方式**（P0）
  - 定义："说话方式"单选 级联/全双工（全双工只在存在支持实时的平台时可选，否则禁用并注明"需要支持实时语音的平台"）；级联显示"转写模型"、"朗读声音"；全双工显示"实时模型"；两者都有"停顿判定"（300–4000 ms，默认 900 ms）。
  - 验收：U 可选性；S。
- **SET-05 即时保存**（P0）
  - 定义：无保存按钮，改动立即生效并持久化。
  - 验收：U。
- **SET-06 隐私说明**（P0）
  - 定义：固定文字："API Key 加密保存在本机。对话内容会直接发送到你选择的平台，本应用不经过其他服务器。"
  - 验收：S。

## 14. NFR 非功能

- **NFR-01 分层**（P0）：每页 State（不可变数据）/ Mapper（领域→State，纯函数）/ Policy（业务规则，纯函数）/ ViewModel（协调用例，暴露 State 流与一次性事件）/ View（只渲染 State、转发意图）。验收：B 架构单测扫描 `ui/ai/**` 源码，不得 import `com.ggec.earbuds.data.`、`com.yovo.lib_ai.`（除 `wiring` 外）。
- **NFR-02 规则可单测**（P0）：Mapper、Policy、格式化不依赖 Android；验收：B 这些类所在包无 `android.` import；U 覆盖率以"每条需求的验收测试存在"为准，列在 `refactor-log.md`。
- **NFR-03 兼容**（P0）：新增字段的记录类保留旧构造函数并给默认值；旧版 JSON 读入不崩溃。验收：U 以当前版本导出的 JSON 样本（存 `app/src/test/resources/ai/legacy/`）读入成功。
- **NFR-04 构建**（P0）：`:app:assembleDebug --offline`、`:app:testDebugUnitTest`、`:lib_ai:testDebugUnitTest` 全过。
- **NFR-05 截图**（P0）：每页适用的七态各一张，文件名 `{页}-{状态}.png`；预检截图（Robolectric）存 `app/doc/ai/captures/`，真机截图存 `app/doc/device-captures/ai/`；`page-spec.md` 七态矩阵引用文件名。
- **NFR-06 颜色**（P0）：只用 YoColors 角色；红色只用于错误与危险操作；强调色只用于可交互元素与"当前"。验收：B `ui/ai/**` 与 AI 布局中无硬编码颜色值。
- **NFR-07 提示方式**（P0）：测试、测速、拉取、保存的结果都写在页面上；toast 只用于"已复制"。验收：B 静态检查。
- **NFR-08 文案**（P0）：界面文案全部来自 `strings.xml`，术语符合 §1；验收：B 检查 AI 相关字符串不含"令牌"、"Token"（大写）、"密钥"、"会话"、"服务商"。
- **NFR-09 流畅**（P1）：流式渲染最多每 100 ms 重排一次；1,000 个历史对话打开面板 <500 ms（真机）。
- **NFR-10 无障碍**（P1）：可点区域 ≥48 dp；图标按钮有内容描述；状态变化（测速结论、连接状态）用 `announceForAccessibility` 或 live region。
- **NFR-11 安全**（P0）：API Key 不进日志、不进错误信息、不进截图（输入框默认掩码）。验收：U 失败信息构造函数过滤 Key。
- **NFR-12 删除与备份**（P0）：重写前对旧 UI 打 git 标签 `ai-ui-v4-backup` 并把旧文档移到 `app/doc/archive/`；用户 Windows 机上的未跟踪目录（`/ui-review/`、`/ui-work/`、`/app/doc/rewrite-drafts/` 等）不在仓库里，由用户自行保留（Q10）。
