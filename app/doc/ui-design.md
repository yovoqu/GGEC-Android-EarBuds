# UI 设计规范（v1）

这份文档是 AI 相关界面的设计依据。页面只引用令牌和构件，不再各自写字号、间距和圆角。

## 1. 调研结论

| 参考 | 取用的部分 |
| --- | --- |
| [Material 3 · Lists](https://m3.material.io/components/lists/overview) | 列表项三档高度：一行 56dp、两行 72dp、三行 88dp；leading / headline / supporting text / trailing 四段式；左侧 16dp 内边距 |
| [M3E ListItem 规格](https://pub.dev/documentation/m3e_core/1.1.3/m3e_core/M3EListItem-class.html) | 同上高度的落地实现：leading 与文字间距 12dp，trailing 与文字间距 12dp |
| [Now in Android](https://github.com/android/nowinandroid) | 用 Material 3 设计体系 + 设计令牌组织 UI；页面、组件、令牌分层，深浅色与动态色都从令牌走 |
| [Material 3 字体阶梯](https://m3.material.io/styles/typography/type-scale-tokens) | Display / Headline / Title / Body / Label 的层级关系，本应用压缩成 7 档 |
| YoUI 组件（youi_kit） | YoButton / YoMenu / YoDialog 保持原生观感；窗口级容器只有 `YoTabs` 一层，页内标题行自己画 |

结论：本应用是「耳机工具的 AI 标签页」，不做对话产品那种落地页。视觉上按系统设置/消息类应用的做法：
信息密度适中、层级靠字号和留白区分、只有一处主色强调，避免装饰性图标块和大面积色块。

## 2. 设计原则

1. **层级靠字号和留白，不靠色块。** 一个页面最多一处主色（主按钮或当前态）。
2. **一行只做一件事。** 行高固定 56/72，四段式：图标、标题（+副标题）、右侧值、箭头/开关。
3. **图标是线性的，不加底板。** 只有平台头像用圆形底；行内图标 20dp、颜色 textSecondary。
4. **卡片是容器，不是装饰。** 16dp 圆角、无阴影、靠背景色和 1px 分隔线区分。
5. **对话页只有两个平面。** 页面底色 + 内容；描边容器只有两处——空状态里的建议卡和输入胶囊。

### 2.1 品牌色的语义（第三轮评审后收敛）

蓝色只表示两件事：**主操作**、**正在发生的事**。逐屏统计后每屏至多三处：

| 页面 | 蓝用在哪 | 是不是"操作/进行中" |
| --- | --- | --- |
| 对话页 | 通话入口、发送键、流式中的停止键 | 是（入口 + 主操作 + 进行中） |
| 设置页 | 身份卡「更换」、提示词行的可点区域 | 是（换平台是这一页的主操作；提示词是这一页唯一可改的生成项） |
| 平台详情页 | 拉取/新建/勾选所在的行首图标、选中勾 | 是（操作 + 选中） |
| 通话页 | 光晕（聆听/思考/说话）、重试键 | 是（声音在流动 + 断线后的主操作） |
| 历史面板 | 无 | —— |

不表示：导航选中、普通链接、静态强调。底部导航栏的选中蓝属于 App 外壳，不在本模块的收敛范围。

评审提出"选中应改用勾与字重"，我们保留品牌勾：它旁边始终带着一个勾形，颜色不是唯一信号，换成墨色反而削弱"选的是它"。
## 3. 令牌

### 3.1 颜色（全部来自 YoUI 主题，随深浅色切换）

| 令牌 | 用途 |
| --- | --- |
| `background` | 页面底色（snowGray 1） |
| `surface` | 卡片、输入框、面板 |
| `surfaceVariant` | 次级填充：标签底、推理块、登录态气泡 |
| `textPrimary / Secondary / Tertiary / Quaternary` | 正文 / 说明 / 辅助 / 占位 |
| `accent / onAccent / accentSoft` | 主操作、当前态、发送按钮、用户气泡 |
| `danger / warning / success` | 错误、截断、测速结果 |
| `hairline` | 1px 分隔线和描边（textPrimary 8%~12%） |

### 3.2 字号

| 名称 | 字号 | 用途 |
| --- | --- | --- |
| `TEXT_DISPLAY` | 28 | 页面大标题（由 YoPage 负责，页面内基本不用） |
| `TEXT_HEADLINE` | 20 | 空状态标题、对话开场 |
| `TEXT_TITLE` | 17 | 卡片标题、设置分组标题 |
| `TEXT_BODY` | 15 | 行标题、消息正文、输入框 |
| `TEXT_CALLOUT` | 14 | 说明文字、按钮文字 |
| `TEXT_SUBHEAD` | 13 | 副标题、分组标签、标签文字 |
| `TEXT_CAPTION` | 12 | 值、页码、模型名、脚注 |
| `TEXT_OVERLINE` | 11 | 预留 |

### 3.3 间距与圆角

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32
- 圆角：标签 8、建议行 12、控件 12、卡片 16、胶囊输入框 24、面板 24
- 页边距 20；卡片内行内边距 16；行高 56（一行）/ 72（两行）；标题行 56
- 图标：行内 18–20、箭头 16、头像 32；可点图标按钮 40dp
- 空状态标题距内容区顶部 88，三种空状态共用这个起点

## 4. 构件（当前实现）

| 构件 | 说明 |
| --- | --- |
| `ui/ai/AiTheme` | 颜色、字号、间距、圆角与背景/文本/图标工厂；颜色全部来自 YoUI 主题快照 |
| `ui/ai/AiKeyboard` | 输入法收起（对话框与输入区共用） |
| `ui/ai/AiDialogs` | 只保留确认框；统一走 `YoDialog.Builder.show()` |
| `ui/ai/chat/*` | 对话页、消息视图、输入区、空状态、窗口留白；标题行由页面自绘，按钮/输入框优先用 YoUI 组件 |
| `ui/ai/widget/MarkdownView` 等 | 库没有的富文本/Markdown/打字动画等必要自绘 |
| `ui/common/YoUi` `YoComponents` `YoPageActivity` | 宿主接入：edge-to-edge、顶部留白归属、页面级组件释放、页面基类 |

## 5. 页面布局

### 5.1 对话页

这一页不使用 `YoPage`：`YoTabs` 是窗口根容器，两者都是窗口级壳，库的两处 javadoc 明确禁止嵌套。
去掉之后顶部留白和底部避让都归这一页（`AiChatInsets` 一个消费者），标题行改成页内 56dp 的一行。

```
页面根（顶部只吃状态栏）
├─ 标题行 56dp：左「历史」40dp + 「AI」20sp Medium，右「通话」「设置」40dp + 「新对话」40dp
│   ├─ 历史常驻：它是"我在哪条对话里"的入口，位置在标题之前
│   ├─ 通话常驻但只在有可用模型时可见（没有模型时点进去只会看到一句失败）
│   └─ 新对话在空对话时 INVISIBLE，位置保留
├─ 1px 分隔线：只在消息滚起来之后淡入，停在顶部时不出现
├─ 内容区（权重 1）
│   ├─ 有消息：RecyclerView（用户气泡靠右、助手消息靠左），底部 8dp
│   ├─ 无消息：空状态，三种状态共用同一个起点（内容区顶部 88dp）
│   │   ├─ 平台就绪：20sp 提问 + 14sp 说明 + 卡片内 4 行 56dp 建议
│   │   │   （18dp 图标 / 15sp 文字 / 16dp 箭头，行间 1px 且左右各缩进 16dp，整行可点）
│   │   ├─ 未接入平台：状态标题 + 说明 + 12sp 脚注，不放按钮（配置入口在右上角设置）
│   │   └─ 无可用模型：同上，不带脚注
│   ├─ 存储失败横幅（横跨顶部）
│   └─ 回到底部 36dp 圆形按钮（叠在内容区底部居中）
└─ 输入区：12sp 模型行 + 48dp 描边胶囊
    ├─ 模型行：`平台 · model`，字号 12sp、颜色 textTertiary；没有模型时整行隐藏
    └─ 胶囊：24dp 圆角、card 底 + 1px 描边、16sp 输入、右侧 36dp 发送（可发时填品牌色）
```

- 用户消息：`accentSoft` 气泡，右上/左下 18dp、右下 6dp，最大宽度 78%。
- 助手消息：12sp 模型名 → 15sp Markdown 正文 → 操作行（复制/重试/删除，40dp 图标）＋ 12sp 耗时/token。
- 思考过程：`surfaceVariant` 圆角块，标题 13sp，展开后 13sp 正文。
- 输入区在不可用时换成 `fill` 底色、提示语改成「先接入平台，再开始对话」，发送按钮留在原位不变灰消失。

### 5.2 页面范围

应用一共三个主页：**设备、AI、我的**，都在底部悬浮标签栏里。AI 页签进来是对话页，从它进四个二级界面：

| 界面 | 入口 | 结构要点 |
| --- | --- | --- |
| 历史记录（面板） | 标题行左侧「历史」 | `YoSheet` large；行＝勾/对话框图标 + 标题 + 摘要（两行截断）+ 右侧「时间 · 更多」；当前那条用品牌色勾 + 加粗标题；底部「清空全部」破坏色 + 二次确认 |
| AI 设置（页面） | 标题行「⋯」菜单里的「设置」 | 页头（返回 + 页名 20sp + 1px 线）+ **接入形态**（页面最上方两段：文本模式 / 语音交流模式，两段都可点）/ **身份卡**（首字母方块 + 平台名 20sp + 当前模式选中的模型 +「更换」）/ 分区随模式切换（文本→回答风格；语音→语音链路）。生成参数与用量都不在这页 |
| 平台详情（页面） | 身份卡「更换」菜单 / 添加平台 | 四个区块固定顺序：**连接**（测试连接，结果显示在行上 + API Key）→ **模型**（`模型 · N 个` + `全部测速`；行：勾 · 名称 · 首字·上下文 · ⋯）→ **高级**（默认收起，展开为名称 / 接口地址 / 协议）→ **危险区**（删除平台，卡外左对齐）。测速是区块动作不是列表行；进行中的行显示「测速中…」 |
| 历史面板（Sheet） | 标题行「历史」 | 面板头（页名 20sp + 新建图标）→ 三种状态之一：加载「正在读取对话…」/ 空「还没有对话」+「开始新对话」/ 读取失败「没能读取对话记录」+「重试」；有内容时是列表：勾/会话图标 + 标题（≤16 码点，一行）+ 摘要（Markdown 已纯文本化）+ 时刻 + ⋯ 菜单，末尾一行「清空全部」 |

- 通话页的四种可见状态：聆听（品牌蓝呼吸）、思考、说话（外扩）、已静音（中性深灰、停止呼吸）、失败（警示色、静止）。
- 拍照按钮这一版**只有按钮**：点击给一句「通话中插入照片还没开放」，没有选择、上传、解析、发送的任何代码。
- 历史面板与设置页里的「配置入口」不再解释"为什么没有入口"——入口已经回来了，文案只说状态。

## 6. 状态矩阵（逐页核对）

每个页面都必须回答"它还可能是别的什么样子"。下表是这一版的实际实现，✗ 表示还没做。

| 页面 | 加载 | 空 | 内容 | 错误 | 离线 / 无权限 | 禁用 |
| --- | --- | --- | --- | --- | --- | --- |
| 对话页 | 首帧直接画骨架，无独立加载态（本地读盘） | 就绪态一句话 + 语音提示（有实时模型时）/ 未接平台 / 无模型，三种文案 | 消息流；流式中发送键变停止；思考过程收起 | 失败卡：平台原文 + 重试；存储失败横幅 | **有意不做预检**：断网时请求会立刻失败，失败卡写「网络连接失败，请检查网络后重试」。预检会误判 VPN/认证页，多一层拦路 | 输入条整体禁用并写明原因 |
| 历史面板 | 「正在读取对话…」（读完即换成内容） | 「还没有对话」+ 「开始新对话」 | 行：勾/图标 + 标题（≤16 码点，一行）+ 摘要 + 时刻 + ⋯ | 「没能读取对话记录」+「重试」（首次失败）；已有内容时保留旧行只弹一次 toast | 不适用（纯本地） | 无 |
| 设置 | 「正在读取设置…」 | 身份卡变「还没有接入平台」+「添加平台」 | 身份卡 / 分段控件 / 回答风格一行 | 事件 toast（保存失败） | 不适用 | 全双工段置灰 + 一行原因 |
| 平台详情 | 无（读完才画） | 模型区「还没有模型」 | 模型列表 + 连接折叠区 + 删除块 | 拉取失败 / 测速失败走 toast | 不适用 | 内置平台名称不可编辑、单协议时协议不可选 |
| 通话页 | 「正在接通」（CONNECTING） | 不适用 | 聆听 / 思考 / 说话 / 静音 四态 + 真实电平 | 失败态：原因 + 「去设置」；结束后挂断降级 | 权限被拒：写明缺哪个权限 | 无模型时不出现通话入口 |

五页 × 六格全部有实现或写明为何不做，没有遗留的 ✗。

两处只有代码依据、没有真机画面：**思考过程的收起态**（DeepSeek 不返回 reasoning，设备上永远不出现这一块）与**静音态的光晕静止**（本机语音链路进不到聆听，见 §14.3）。这两项不当成"已验收"。）

## 7. 不要做的事

- 不要给每行图标加圆角底板（模板感最强的一处）。
- 不要用厂商品牌色区分平台，只用中性头像 + 名称。
- 不要在空状态用居中大图标、渐变、胶囊大按钮和营销文案。
- 不要把同一句状态同时写在页头副标题和输入区里。
- 不要出现第三种圆角或第三种页边距；新增尺寸先进 `AiTheme`。
