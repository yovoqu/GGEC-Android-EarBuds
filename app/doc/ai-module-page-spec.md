# AI 模块 页面级完整规格

> 每一页：**放什么内容**（逐字段，含数据来源）、**每个组件怎么处理**（状态、交互、边界）。
> 与 `ai-module-requirements.md`（要什么）和 `ai-module-component-spec.md`（为什么这么设计）配套。
> 标 ⚠️ 的是需要你拍板的开放项，共 14 条，集中在文末。

## 0. 全局约定

| 项 | 值 |
| --- | --- |
| 页边距 | 20dp（列表卡内 16dp） |
| 字号 | 20 标题 / 15 正文 / 13 副文 / 12 说明 |
| 行高 | 单行 56dp，双行 72dp，三行 88dp |
| 触控 | 最小 40dp，圆钮 56dp |
| 圆角 | 卡 16 / 输入 24 / 行 12 |
| 分隔 | 1px `divider`，仅在同卡内相邻行之间 |
| 颜色 | 品牌色只给主操作与进行中；破坏色只给删除类；内容一律中性 |
| 文案 | 中文；数字与单位间不加空格（`1.4 s` 例外，可读性优先） |

## 1. 对话页

### 1.1 页头（高 56dp，固定不随内容滚动）

| 元素 | 内容 | 来源 | 交互 |
| --- | --- | --- | --- |
| 左：历史 | 时钟图标，20sp 视觉 | 固定 | 打开历史面板 |
| 中：标题 | `AI`，20sp，主文色 | 固定 ⚠️1 | 长按无 |
| 右一：通话 | 波形图标，品牌色，常驻页头 | 进入通话页 |
| 右二：更多 | `⋯` 图标 | 固定 | 菜单：新对话 / 设置 |

**状态**：通话图标在无语音能力时**隐藏**（不是禁用——禁用会让人反复点）。
**边界**：标题不显示当前模型（模型在每条回答上方标）；不在页头显示未读数/红点。

### 1.2 消息流

- 布局：纵向列表，用户消息右对齐、助手消息左对齐通栏。左右边距 20dp。
- 滚动：默认贴底；用户上滑后停止自动滚动；重新贴底的条件是"用户手动滑到底"或发送新消息。
- 消息间距：同发送者相邻 8dp，换发送者 20dp。
- **状态**：
  - 空：显示空态（见 1.3）
  - 有内容：正常流
  - 加载：本地读盘，不显示骨架屏（<150ms）
  - 错误：单条消息级的错误卡（见 1.6）

### 1.3 空态

| 元素 | 内容 | 条件 |
| --- | --- | --- |
| 主文案 | `耳机有什么问题？` 20sp 主文色 | 恒显示 |
| 副文案 | `直接问，或者点右上角通话说给它听`，13sp 次文色 | 仅当有语音能力 |
| 变体 A | `还没有接入平台` + 按钮`去设置` | 未配置任何平台 |
| 变体 B | `还没有可用模型` + 按钮`去添加` | 有平台但无模型 |

- **不做**：示例问题、插画、渐变、营销语。
- 位置：垂直居中偏上（约屏高 38% 处），不随键盘移动。

### 1.4 用户消息

| 元素 | 内容 | 说明 |
| --- | --- | --- |
| 气泡 | 15sp 主文色，底色 `fill`，圆角 `18,18,6,18`，内边距 15/10 | 最大宽度 82% 屏宽 |
| 长文本 | 超 6 行折叠 + `展开` | 避免一屏全是自己的话 |
| 操作 | 长按 → 菜单：复制 / 删除 | 不做常显图标（用户消息不是主角） |

### 1.5 助手消息

| 区块 | 内容 | 状态 |
| --- | --- | --- |
| 模型标签 | 当前模型的 id（平台返回或手填）12sp 三级色 | 切换模型后新消息才变 |
| 思考过程 | `思考过程 · 12s` 一行，可展开；流式中显示 `正在思考…` | 无 reasoning 时**整块不出现** |
| 正文 | 15sp，段落间距 12dp；代码块 `fill` 底 + 等宽；有序/无序列表悬挂缩进 | 流式中逐字追加 |
| 元信息 | `786 ms · 47 tok/s · 37 tokens` 12sp 三级色，右对齐 | 无 usage 时只显示耗时；无数据则整行隐藏 |
| 操作 | 复制 / 重发 / 删除 三个图标，40dp 触控 | 流式中隐藏；重发仅最后一条可用 |

- **错误卡**：替换正文，显示 `回答中断` + 原因（平台原文）+ `重试`；保留已生成的部分内容在上方。
- **停止后**：保留已输出内容，元信息冻结为实际值。

### 1.6 输入条（贴底，随键盘上移）

| 元素 | 状态 |
| --- | --- |
| 输入框 | 单行起，最多 5 行；placeholder `输入消息…`；禁用时 placeholder 变 `先接入平台` |
| 发送键 | 空输入：浅灰 40% 且 disabled；有字：品牌圆底白箭头；生成中：品牌圆底停止方块 |
| 模型提示行 | **仅在无模型时**出现，13sp，写原因 |

- 边界：仅空白字符视为空；发送后立即清空并保持焦点；IME 弹出时不遮挡输入条。
- ⚠️2 是否在输入条内提供"重新生成上一条"的长按入口。

### 1.7 流式指示

- 位置：助手消息模型标签下方。
- 形态：三点跳动 + 可选实时速度（⚠️3 实时速度需要流式 token 计数，当前未实现）。

### 2.2 列表行（双行 72dp）

### 2.3 四态

| 态 | 表现 |
| --- | --- |

- 位置：列表卡之外、面板底部、左对齐 20dp，13sp 破坏色。

## 3. 设置页

### 3.1 接入形态（页面最上方的分段）

| 段 | 内容 | 接什么 |
| --- | --- | --- |
| 左 | `文本模式` | DeepSeek 这类对话模型，走 Chat Completions / Messages / Responses |
| 右 | `语音交流模式` | APP 预设的语音模型（ChatGPT / Qwen），一条 WebSocket 直连 |

- 两段永远可点：切过去只是换一套配置，不要求目标模式已经配好。
- 切换即时持久化，并决定下面画身份卡还是语音模型卡。
- 分段下方一行说明当前模式接什么（`接入 DeepSeek 这类对话模型…` / `选一个预设语音模型，填好它的 Key 就能直接通话`）。

### 3.2 身份卡（仅文本模式）

| 字段 | 内容 | 交互 |
| --- | --- | --- |
| 平台名 | 20sp 主文色，文本模式选中的平台 | — |
| 当前模型 | 13sp 次级色，显示选中的对话模型 | — |
| 更换 | 品牌色 15sp | 菜单：平台列表 + `添加平台`；进入平台详情 |

- 空态：`还没有接入文本模型`，副行说缺哪一类模型。
- 语音模式不画这张卡：语音模型与平台无关，画在一起会让"删平台"看起来也会删语音。

### 3.3 语音模型卡（仅语音模式）

| 字段 | 内容 | 交互 |
| --- | --- | --- |
| 语音模型 | ChatGPT / Qwen，当前项标「当前」 | 下拉菜单切换 |
| API Key | `已填写` / `未填写` | 点击弹窗粘贴；留空保存等于清掉这一家的 Key |

- 预设表在代码里（`AiVoiceModel`）：端点、模型 id、协议都写死在预设中，界面不拼地址。
- 两家 Key 各存一份，切换预设不会把另一家的 Key 顶掉。
- 未填 Key 时不算配好：对话页的通话入口不出现，避免点进去看一句失败。

### 3.4 参数（已下线）

> 2026-10-29：整个参数区移除。温度 / top_p / 最大输出 / 上下文条数由 APP 在发请求时给定默认值
> （`AiGenerationDefaults`），界面不再提供开关、作用范围、滑杆或模型覆盖入口。
> 原「全局参数 + 模型参数」两级方案与「批量应用到全部模型」一并删除。

### 3.5 回答风格（仅文本模式）

| 元素 | 内容 |
| --- | --- |
| 系统提示词 | 单行摘要，默认 `默认提示词`；点击 → 多行编辑对话框 |

这是文本模式唯一可改的生成相关项；语音模式不显示这一分区。

### 3.6 用量（已下线）

> 2026-10-29：用量分区整体移除。设置页不再展示请求次数 / 令牌 / 费用，
> 也不再写 `usage/requests.jsonl` 账本——记录与读取的代码一并删除。
> 每条消息自己的 token 元信息仍在对话气泡上显示，那来自平台响应的 `usage`，与账本无关。

## 4. 平台详情页

### 4.1 页头

| 元素 | 内容 |
| --- | --- |
| 返回 | 左箭头 |
| 标题 | 平台名 20sp；内置平台用模板名 |
| 徽章 | `官方`（内置模板）/ 无（自定义） |

### 4.2 连接区

| 行 | 主文案 | 右值 | 状态 |
| --- | --- | --- | --- |
| 测试连接 | `测试连接`；副行显示地址 | `连接正常 · 首字 1.4 s` / `连接超时` / `连接失败` / `测试` | 测试中行内显示 `测试中…` |
| API Key | `API Key`；副行遮罩 | 眼睛图标 | 未填时副行 `未填写`，测试行禁用并写 `先填 API Key` |

- 结果随配置持久化；不弹 toast。

### 4.3 模型区

**模型来源只有两种**：平台 `GET /models` 拉回来的真实模型，或用户手填的模型 id。
APP 不预置任何厂商默认模型（没有 `deepseek-chat` 这类内置清单），也不在拉取后自动选中——
列表里出现什么，只由平台返回和用户输入决定。

| 元素 | 内容 |
| --- | --- |
| 区块头 | `模型 · 3` 12sp 三级色；右侧动作 `全部测速` / `停止`（品牌色 12sp） |
| 行 | 勾（选中）/ 对话图标 · 名称 15sp · 事实行 13sp · `⋯` |
| 事实行 | `首字 889 ms · 1M 上下文`；测速中替换为 `测速中…`；失败为 `测速失败`/`超时` |
| 添加模型 | `＋ 添加模型`，点击 → 菜单：拉取模型 / 手动添加（手填 id 即自定义模型） |
| 空态 | `还没有模型` + 副行 `拉取列表或手动填一个模型 id` |
| ⚠️8 搜索 | 模型 > 8 时标题下出现搜索框（当前未实现） |

- ⋯ 菜单：测这一条 / 删除模型（破坏色）。
- 测速结束：区块头动作恢复 `全部测速`，若全部完成可在标题右侧追加 `最快：<模型名>`（⚠️9 是否要与动作争位）。

### 4.4 高级区（默认收起）

| 展开态行 | 内容 |
| --- | --- |
| 名称 | 平台名（内置不可改，无箭头） |
| 接口地址 | URL；点击编辑（校验 https / 私有地址 http） |
| 协议 | `Chat Completions`；多协议时可切换 |

- 收起态：一行 `Chat Completions · https://api.deepseek.com`。

### 4.5 危险区

- 一行 `删除平台`，破坏色 15sp，卡外左对齐，上距 32dp。
- 点击 → 二次确认（说明会同时删除该平台的模型与测速记录）。

## 6. 通话页

### 6.1 页头

| 元素 | 内容 |
| --- | --- |
| 关闭 | `×` |
| 标题 | `语音通话` 20sp |
| 副标题 | `实时语音对话`（固定，不再按模式切换） |

### 6.2 光晕

| 状态 | 表现 |
| --- | --- |
| 接通中 | 静止，中性浅环 |
| 聆听 | 呼吸 + 半径随真实电平 |
| 思考 | 慢呼吸 |
| 说话 | 快呼吸 |
| 静音 | 静止，中性 |
| 失败 / 结束 | 静止，中性灰盘，无光晕 |

### 6.3 状态行

- 单行：`正在聆听` / `正在思考` / `正在说话` / `已静音`。
- 失败两行：结论 15sp + 原因 13sp 次级色。

### 6.4 失败出口

| 失败类型 | 主按钮 | 次按钮 |
| --- | --- | --- |
| 可修（无模型/鉴权/接口缺失） | `去设置`（品牌胶囊） | 无（重试无用，故隐藏） |
| 临时（网络/超时/服务端/限流） | `重试`（品牌胶囊） | 无（去设置无用，故隐藏） |

### 6.5 控制排（四个 56dp 圆钮）

| 钮 | 图标 | 状态 |
| --- | --- | --- |
| 拍照 | 相机 | 占位：点击 toast `通话中插入照片还没开放` |
| 麦克风 | 麦克风 / 划掉 | 静音态换图标 + 描边 |
| 扬声器 | 扬声器 / 听筒 | 开＝品牌淡底 |
| 挂断 | 电话 | 结束时降级为中性 `结束通话`；失败/结束后其余三钮置灰 |

- ⚠️11 是否需要文字标签（我倾向无，图标语义足够）。

## 7. 通用组件

| 组件 | 规格 |
| --- | --- |
| 输入对话框 | 标题 + 单行输入 + `取消/保存`；校验失败在输入框下方红字 |
| 二次确认 | 标题 + 说明 + `取消/确认`；破坏性动作确认键用破坏色 |
| 菜单 | 跟随锚点，最多 6 项，破坏项置底并着色 |
| Toast | 仅用于"操作已生效"（已复制、已删除）；不承载状态 |
| 空态 | 一句真话 + 一个动作；不带插画 |
| 加载 | 一句进行中的话；**不用骨架屏**（本模块数据都在本地，慢不到需要骨架） |
